# Ecosystems

Ecosystems group multiple organisms into a complete feature.

They coordinate UI and business behavior for a specific domain.

## Characteristics

- Feature-oriented
- Composed of organisms, molecules, and atoms
- May use composables and stores
- Can coordinate business logic

## Examples

- Header.vue
- Footer.vue

## Guidelines

✅ Use composables.

✅ Access stores when needed.

✅ Coordinate feature behavior.

❌ Avoid page layout concerns.
