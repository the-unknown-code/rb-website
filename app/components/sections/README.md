# Sections

Sections compose ecosystems and organisms into page-specific layouts.

They represent large portions of a page and are typically imported directly into Nuxt pages.

## Characteristics

- Page composition
- Layout-focused
- Can use composables
- Can orchestrate multiple ecosystems

## Examples

- HomeHeroSection.vue
- PricingSection.vue
- FAQSection.vue
- ContactSection.vue

## Guidelines

✅ Compose ecosystems and organisms.

✅ Keep layout responsibilities here.

✅ Connect page data to UI.

❌ Don't duplicate reusable feature logic.
